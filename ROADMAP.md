# Roadmap

Audience of One v0.1 is a macOS control room with an optional Android listening
endpoint. It runs a receipt-driven programme rundown through
Spotify Premium, owned local files, or the QQ Music companion route. Spotify
Free remains an assisted Mac experiment.

The next useful pieces are:

- live rundown editing and prepared-voice revision while a show is already on air;
- pre-synced local-file playback on Android;
- a Windows control room with the same programme, receipt, and fader contract;
- an iPhone listening endpoint if background audio and control can preserve the
  same honest receipt model;
- an optional scene runner for prepared multi-act fader performances.

These are directions, not promises hidden behind v0.1 commands. The current
surface is documented in `README.md`, `docs/DESKTOP-QUICKSTART.md`, and
`android/README.md`.
